# NSZ integration

Eden Custom can download the official NSZ command-line tool on demand for
NSZ -> NSP conversion.

Pinned tool:
- Project: nicoboss/nsz
- Version: 5.0.0
- Asset: nsz-cli-windows-x64.exe
- SHA-256: 341b395c18679bf4c01f0bf2fb0e22e315a64b34fad51064781f5155a978883d
- License: MIT

The converter is not used by the emulation core. It is invoked only from the
Content Converter frontend and the downloaded binary is accepted only after
the pinned SHA-256 digest matches.

Eden Custom does not ship console keys, firmware, games, updates or DLC.
